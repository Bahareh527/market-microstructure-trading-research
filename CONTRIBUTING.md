# Contributing

Contributions are welcome when they preserve the clean-room and research-only
character of the project.

1. Open an issue describing the proposed change.
2. Do not submit confidential, employer-owned, licensed, or personal market data.
3. Add tests for behavioral changes.
4. Run python -m pytest and python scripts/check_repository.py before opening a pull request.
5. Cite any external algorithm, dataset, or implementation that influenced the change.
